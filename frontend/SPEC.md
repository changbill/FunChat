# 프런트엔드 명세

- 채팅방 생성 시 일반(TEXT) 또는 영상(VIDEO)을 선택한다. 목록은 서버 페이지네이션과 유형 필터를 사용한다.
- `/room/:roomId`는 서버 상세 응답으로 유형을 결정한다. 기존 방은 TEXT로 취급한다.
- 일반방은 STOMP 텍스트 채팅, 영상방은 텍스트 채팅과 LiveKit 통화 패널을 함께 제공한다.
- 영상은 사용자가 참가를 눌러야 연결하며 최초 카메라·마이크는 꺼져 있다. 사용자가 켜면 브라우저 장치 권한을 요청한다.
- 영상 참가 토큰은 백엔드에서 발급하며 메모리에만 보관한다. 연결 오류, 권한 오류와 재참가 UI를 제공한다.
- 통화 나가기는 미디어 연결만 종료하고, 방 나가기는 방 참여도 종료한다. 화면 이탈 시 미디어 트랙을 해제한다.
- 새로고침은 같은 방 재입장으로 복구한다. 브라우저 탭 종료에는 방 퇴장 요청을 보내지 않으므로 참여 상태가 남을 수 있다(서버 presence/webhook 정리는 후속 작업).
